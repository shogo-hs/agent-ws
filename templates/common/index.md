# 共通ナレッジ（案件をまたぐ自社の事実）

ここに置くのは、どの案件でも同じ自社の事実だけ: 組織図・決裁範囲・社内システムの一覧・標準手順・共通用語。
進捗・数値・案件ごとの決定は案件の `projects/<案件>/knowledges/` に置く。同じ語・同じ事実が両方にあれば案件側が勝つ
（顧客の組織図は案件、自社の組織図はここ）。
3 ヶ月以内に変わりそうなことは書かない。1 ファイル 1 担当（frontmatter の `owner`）。`updated` が 90 日を超えると `scripts/ws doctor` が警告する。
足すときは `scripts/ws know new --common "タイトル" --owner "担当"`、用語は `scripts/ws glossary add --common "正式表記" ...`。
