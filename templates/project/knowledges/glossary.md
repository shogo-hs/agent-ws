# 用語集（{{project}}）

- 「誤変換・別表記」に書いた文字列は、`scripts/ws transcript normalize` がそのまま「正式表記」に置換する。
  1文字の語や一般語（「移行」「対応」など）は誤爆するので書かない。
- 「読み」は人が音で探すためのもの。スクリプトは使わない。
- 「関係」は `→種類: 相手` をカンマ区切りで（例 `→担当: 鈴木, →依存: 受注管理 API, →置き換え: 8 台案`）。空でよい。
  3 ヶ月程度変わらない関係だけ書く。進捗や数値は書かない（腐る）。
- 行の追加は `scripts/ws glossary add {{project}} "正式表記" --reading "よみ" --alias "誤1, 誤2" --desc "説明" --relation "→担当: 誰"`。
