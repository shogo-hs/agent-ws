# _example（サンプル案件）

## 概要
架空の顧客「ACME 社」の業務システムを Kubernetes に移行する案件、という設定のサンプルです。
フォルダの使い方と、会議の文字起こしを用語集で直してナレッジにする流れを見るためのもので、内容はすべて架空です。
自分の案件を作るときは `scripts/ws project new <name>` で新しく作り、このフォルダは消して構いません。

## この案件での決まりごと
- 週次定例は毎週火曜 10:00。文字起こしは `tasks/<当日のタスク>/references/` に残す。
- 決定事項は `knowledges/` に昇格する。会議のまとめ自体はタスクの中に置く。

## 中身

- [tasks/](tasks/index.md) — この案件のタスク。作業中は自分のタスクだけを見る
