# Palantir

## 引用した記述（原文のまま。要約しない）
- "AIP Logic can now be automated such that Ontology edits can be automatically applied or staged for human review."
- "you can see an overview of Agent proposals that were generated and require a review by navigating to the **Proposals** tab using the left side navigation bar."
- "When you accept a proposal, the Action will be automatically executed, and the proposal card will be moved to the **Applied** column."

## このタスクでの使いどころ（使わなかったなら理由）
`scripts/wsonto/README.md` の `engine.act` が承認要のときに `proposals/P-NNNN.json` を書いて実行待ちにし、`cli.py` の `proposals` コマンドで一覧を出し、`approve`（人だけ）で実行する設計の直接の根拠。Palantir の「Proposals タブで人がレビューし、承認すると Action が実行される」という仕組みと、wsonto の「実行待ち → 承認 → 実行」の流れが対応する。
