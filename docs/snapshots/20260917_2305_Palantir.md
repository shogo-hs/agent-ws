# Palantir

## 引用した記述（原文のまま。要約しない）
- "An action is a single transaction that changes the properties of one or more objects, based on a user-defined logic."
- "An **action type** is the definition of a set of changes or edits to objects, property values, and links that a user can take at once. It also includes the side effect behaviors that occur with action submission."
- "Any changes made to objects, property values, and links will be committed to the Ontology when the user takes the action and will be reflected in all user applications."

## このタスクでの使いどころ（使わなかったなら理由）
`scripts/wsonto/README.md` の `action_types` の設計（`parameters`・`rules`・`approval`・`criteria` を持つ 1 つの定義がトランザクションとして `objects.json` を書き換える形）の根拠。「1 つ以上のオブジェクトを変える単一のトランザクション」という定義が、wsonto の `engine.act` が snapshot 上にルールを適用してから一括で validate・commit する設計と対応する。
