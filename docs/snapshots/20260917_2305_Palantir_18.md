# Palantir

## 引用した記述（原文のまま。要約しない）
- "**Submission criteria** (formerly known as validations) are the conditions that determine whether an action can be submitted."
- "A condition can be configured using one of three condition templates: “Current user”, “Parameter”, or "Execution context"."
- "The failure message will be displayed to the end user across Foundry (Object Explorer, Workshop, or Quiver) whenever a condition is not met. The failure message informs the user about why they are blocked from submitting an Action."

## このタスクでの使いどころ（使わなかったなら理由）
`scripts/wsonto/README.md` の `action_types.criteria`（`{"when": "<式>", "message": "<雛形>"}` の一覧。前提条件を満たさないものの message を全部集めて拒否理由にする `engine.act` の②の設計）の根拠。「Current user」「Parameter」というテンプレートの分類は、wsonto の式が `actor`（現在の実行者）と引数・実体のプロパティを同じ式言語で参照できる設計（`expr.py`）に対応する。「満たさないときの失敗メッセージ」がそのまま `criteria` の `message` の役割。
