## 引用した記述（原文のまま。要約しない）
- After each turn, a model checks whether the condition holds.
- if the model judges the condition impossible to satisfy
- Setting a goal starts a turn immediately, with the condition itself as the directive.
- It doesn't run commands or read files independently
- Run `/goal clear` to remove an active goal before it resolves.
- `/goal` is a wrapper around a session-scoped [prompt-based Stop hook](/docs/en/hooks#prompt-based-hooks).
- If a subagent or a background shell command is still running when a turn ends, Claude Code skips the evaluation for that turn.
