- Run `/rewind`, or press `Esc` twice when the prompt input is empty, to open the rewind menu.
- **Restore code and conversation**: revert both code and conversation to that point
- Checkpointing does not track files modified by Bash commands.
- Claude Code usually doesn't capture those edits in your session's checkpoints.
- For permanent version history and collaboration, continue using version control, such as Git
