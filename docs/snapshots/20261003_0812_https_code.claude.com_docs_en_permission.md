# https://code.claude.com/docs/en/permissions.md

## 引用した記述（原文のまま。要約しない）
- Permission rules are enforced by Claude Code, not by the model.
- Rules are evaluated in order: deny, then ask, then allow.
- An allow rule can't carve an exception out of a deny rule.
- If you write a path rule for `Write`, `NotebookEdit`, `Glob`, or the legacy `MultiEdit` tool instead, Claude Code accepts the rule but never consults it
- or to arbitrary subprocesses that read or write files indirectly, like a Python or Node script that opens files itself. For OS-level enforcement that blocks all processes from accessing a path, [enable the sandbox](/docs/en/sandboxing).
- to make the file tools refuse the paths it fences in every permission mode.
