# 0008. 安いモデルの調査係へ渡す仕事は 4 条件で決める
- 状態: 採用 / 日付: 2026-09-06

## 状況
本線は高いモデルのまま、読む量が多く判断の軽い仕事を安いモデルに逃がしたい。だが「何でも渡す」と判断の要る仕事まで安いモデルがこなした振りをし、細かく何度も渡すとサブエージェントは親のキャッシュを使えないので割高になる。
## 決定
次の 4 つを満たす仕事だけ `researcher` に渡す: ①出力を機械で確かめられる ②読む量が多く返すものが短い ③本線が途中経過を知らなくても判断できる ④手順が有限で判断の分岐が少ない。1 回でまとめて渡し、成果物の有無と引用の有無で確認し、本文は本線に持ち込まない。受け皿は Claude Code が `.claude/agents/researcher.md`（haiku）、Codex が `.codex/agents/researcher.toml`（gpt-5.4-mini・low）と `[agents]` の既定モデル。
## 理由
Anthropic・OpenAI の公式文書は、分類・抽出・通読のような定型の支援作業を安いモデルへ渡し、難しい判断を本線に残す線引きを示している（台帳 8 本）。0.153.4 の `codex exec` では `spawn_agent` に名前指定が無いので、`[agents]` の既定で子が安いモデルになる保険を置く。bench（trap 大規模 Sonnet・各 5 回）では委譲を許しても Agent 呼び出しは 0 回、費用は 0.161 対 0.165 USD で差が無く、効果は未測定。
## 捨てた案
- スキルの `context: fork` + `model:` でスキル単位にモデルを変える: Codex のスキルにモデル指定が無く、委譲の仕組みが 2 系統になる（transcript-ingest だけは 0007 で fork にした）
- fact-checker 相当のサブエージェントを新設する: 成果物への突き合わせの型がまだ無い。機械で見られる分は `doctor` に入れた
- gpt-5.4-nano を既定にする: mini より判断力が落ちる。比較対象として台帳に残した
## 影響
条件を満たす仕事が無ければ委譲は起きない（bench の結果はそれを示している）。本線に残すもの（目的と進め方・見積の計算・報告文・昇格の判断）は明文化した。
