## 実測（M1・M2。2026-10-03）

- M1: Codex CLI 0.153.4 は `codex exec -m gpt-6-luna` を 400（"not supported when using Codex with a ChatGPT account"）で拒否し、0.160.0 は通る。GPT-6 Luna がモデル一覧に入ったのは 0.156.1（GitHub Releases の rust-v0.156.1、#47405）。`codex exec` では、0.153.4 でも 0.160.0 でも SessionStart の hook は出ず、UserPromptSubmit と Stop は出る（版による差は無い）
- M2: `bench/researcher_effort.py run 5 rule gpt-5.6-luna:max,gpt-6-luna:high,gpt-6-luna:max`（Codex CLI 0.160.0）。結果は `bench/results/runs_effort.jsonl` の末尾 15 行。採点の語「項目定義」が言い換え（「顧客マスタの項目を定義する」）を落としていたので「項目」に直し、この 15 行は直した語で採点し直した（それより前の行は当時の採点のまま）
