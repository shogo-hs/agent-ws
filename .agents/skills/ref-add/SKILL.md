# ref-add

ゴール: 出所・取得日時・原文が `references/` に残り、タスクの `index.md` の一覧に載っている状態。

## 既定の進め方
1. 読む前に `scripts/ws ref add <URL|ファイル>`（`--summary` は省略可、必要なら `--title "…"` `--kind web|file|transcript|chat|person`）を叩く。
   URL なら本文をテキスト化して保存する。ファイルなら中身をそのまま保存する。人からの回答・チャットの抜粋・口頭の情報は、いったんファイルに書いてから `--kind person`（または chat）で追加する。
2. 保存されたファイルを読む。
3. 「引用した記述」（原文のどこを使ったか、改変せず引用）・「このタスクでの使いどころ」・frontmatter の `summary` を埋める。「原文」節は改変しない。

## つまずきどころ
- WebFetch は hook に止められる。理由に出る `ref add` をそのまま叩く。
- 同じ情報源を 2 回保存しない。`index.md` の一覧に既にあれば、そのファイルの「引用した記述」に追記する。
- 出所が言えない情報は記録しない。推測を記録すると次のセッションが事実と誤認する。
- ログインが要るページなど URL から取得できないときは、見えている本文を手でファイルに保存して `--kind file` で追加し、URL は `--title` か「このタスクでの使いどころ」に書く。
