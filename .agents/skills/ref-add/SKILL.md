# ref-add

ゴール: 出所・取得日時・原文が `references/` に残り、タスクの `index.md` の一覧に載っている状態。

## 既定の進め方
1. `scripts/ws ref add <URL|ファイル> --summary "1文" [--title "…"] [--kind web|file|transcript|chat|person]`
   URL なら本文をテキスト化して保存する。ファイルなら中身をそのまま保存する。
2. 人からの回答・チャットの抜粋・口頭の情報は、いったんファイルに書いてから `--kind person`（または chat）で追加する。
3. 保存されたファイルの「要点」節に、原文のどこを使ったか・このタスクでの使いどころを 2〜3 行で書く。「原文」節は改変しない。

## つまずきどころ
- 同じ情報源を 2 回保存しない。`index.md` の一覧に既にあれば、そのファイルの「要点」に追記する。
- 出所が言えない情報は記録しない。推測を記録すると次のセッションが事実と誤認する。
- ログインが要るページなど URL から取得できないときは、見えている本文を手でファイルに保存して `--kind file` で追加し、URL は `--title` か「要点」に書く。
