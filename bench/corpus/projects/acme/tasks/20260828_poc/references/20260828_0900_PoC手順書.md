## 原文（改変しない）
PoC 環境構築手順（2026-08-28）

1. Terraform で VPC のサブネットを追加し、EKS クラスタ（1.30）を作成する
2. ノードグループ（m6i.xlarge）を作成する。台数は負荷試験で 8 / 10 / 12 に変える
3. ECR に受注管理のイメージを push し、Deployment と Service を apply する
4. ALB Ingress Controller を入れ、ALB を 1 つ作る
5. Datadog エージェントを DaemonSet で入れる
6. 負荷試験ツール（k6）から本番ピークの 1.2 倍を 30 分流し、p95 を記録する

注意: DB 接続先の環境変数は PoC 用の RDS を向けること（一度、本番を向いていた）。
