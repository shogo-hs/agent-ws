# 組織図（架空の自社）

## 内容
1 行 1 人か 1 部署。関係は `→所属`（人 → 部署）・`→上位`（部署 → 上位の部署か役職）・`→決裁`（この人・部署が決められる範囲）だけを書く。
人数・売上・進捗のような変わる数字は書かない。異動があった月に担当（owner）が直す。

| 名前 | 役割 | 関係 |
|---|---|---|
| 代表取締役 | 全社の最終決裁 | →決裁: 金額の上限なし |
| 経営企画室 | 全社の計画・月次レビューの主催・この組織図の維持 | →上位: 代表取締役 |
| 営業部 | 案件の受注・顧客窓口 | →上位: 代表取締役 |
| 技術部 | 実装・運用・TechDesk | →上位: 代表取締役 |
| 総務部 | 人事・経理・KinTai | →上位: 代表取締役 |
| 佐藤花子 | 営業部長 | →所属: 営業部, →上位: 代表取締役, →決裁: 見積 500 万円まで |
| 高橋一郎 | 技術部長 | →所属: 技術部, →上位: 代表取締役, →決裁: 外注 300 万円まで |
